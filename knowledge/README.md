# Knowledge Base

This directory captures reusable engineering knowledge extracted from completed contribution investigations.

Do not copy entire issue narratives here. Promote only knowledge that generalizes beyond one upstream case.

Suggested areas:

- `concurrency/`
- `distributed-systems/`
- `messaging/`
- `observability/`
- `database/`
- `agent/`
- `testing/`

A good knowledge note explains:
- the invariant or failure pattern,
- how to detect/reproduce it,
- common incorrect fixes,
- validation techniques,
- applicable trade-offs.
